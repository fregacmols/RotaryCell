# Experimental Hardware

These files document audio-interface experiments developed after or alongside the v0.8 transformer prototype. They are retained for reference but are **not** the v0.8 build standard.

The current preferred next experiment is `ESP-CellCore_Passive_Audio_Board_RevA1.pdf`, which removes both transformers and adds the proposed GPIO36 tone-injection path. It requires bench validation before inclusion in a release.
