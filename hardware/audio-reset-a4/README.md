# Audio and Reset A4 — as ordered

Submitted to JLCPCB on August 27, 2026. These files are an immutable record of
the order. Boards from this package have been assembled and tested in multiple
working RotaryCell conversions, including bidirectional audio and the GPIO35
hardware power-cycle path.

| File type | Included |
| --- | --- |
| EasyEDA schematic source | Yes |
| EasyEDA PCB source | Yes |
| Gerber and drill package | Yes |
| JLCPCB BOM | Yes |
| JLCPCB pick-and-place | Yes |

The design combines the passive, adjustable audio interface with a hardware
power-cycle circuit that operates the LilyGO physical switch path. The required
guide firmware v0.11.1-dev drives its reset trigger from GPIO35.

Do not edit the as-ordered files in place. Place subsequent revisions in a new directory.
