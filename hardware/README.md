# Hardware files

The hardware archive is divided by confidence rather than by date:

- `prototype/` contains the drawing associated with the present working prototype. The Passive Audio Board RevA2 PDF is the current reference drawing; an editable RevA2 source file is not yet archived here.
- `experimental/` contains unfinalized alternatives, intermediate exports, footprint/symbol work, the USB interlock concept, and carrier-board iterations.
- `legacy/` contains older v0.8-era wiring and service documents.

Files in `experimental/` and `legacy/` may conflict with the current build and should not be treated as fabrication-ready. Review connectivity, component values, footprints, power switching, charging protection, grounding, and clearances before manufacturing anything.

Never connect the prototype telephone-line interface or any repurposed rear jack to the public telephone network or energized premises telephone wiring.
