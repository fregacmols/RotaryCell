# RotaryCell Build Guide

RotaryCell converts a traditional rotary telephone into a self-contained, battery-powered cellular telephone while preserving the original telephone and its characteristic operation.

This documentation is the build manual for the project. It is being written and validated against actual hardware builds rather than reconstructed after the fact.

!!! warning "Active engineering project"
    RotaryCell is still under active validation. Before ordering boards or parts, read **Build Status** and note any features or assembly details that have not yet been validated.

## Where to start

If you are building RotaryCell using the current PCBs, work through the guide in this order:

1. **Build Status** — understand what is tested and what remains provisional.
2. **Parts & BOM** — gather the required boards, modules, components, connectors, and mechanical parts.
3. **Assembly Guide** — prepare the telephone, assemble the boards, make the harnesses, and install the hardware.
4. **Hardware Wiring** — use the detailed electrical connection reference while assembling.
5. **First-board Bring-up** — perform unpowered and staged powered checks before connecting everything.
6. **Commissioning & Testing** — verify telephone, cellular, audio, ringing, and control functions.
7. **Firmware** — install or update the RotaryCell software.
8. **Troubleshooting** — diagnose common build and operating problems.

## Build philosophy

The project is intended to remain reversible. The original handset, rotary dial, switch-hook, mechanical ringer, network block, and telephone case are retained. Avoid drilling, cutting, or permanently modifying original telephone components.

As the next physical build is documented, this manual will gain step-by-step photographs, exact mounting details, cable routing, and other details that are difficult to capture reliably after assembly is complete.
