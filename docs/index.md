# RotaryCell engineering notes

These pages are the project's engineering record. The current construction
manual is the **[illustrated RotaryCell build guide](../guide/README.md)**,
published at <https://evilroot.net/RotaryCell/>.

The notes here span the hand-wired prototype, PCB bring-up and later validation.
Where an older note differs from the illustrated guide, follow the illustrated
guide. See [Documentation](README.md) for the current-reference and historical
indexes.
