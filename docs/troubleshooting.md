## Modem recovery

Service code `9999` performs modem diagnostics and software recovery. It should not be treated as recovery from every possible modem lockup; the hardware power-cycle recovery circuitry is still being validated.

## Contributing a failure case

When documenting a problem, record the hardware revision, firmware version, observed behavior, measurements or logs, and the change that resolved it. This helps distinguish confirmed fixes from guesses.
