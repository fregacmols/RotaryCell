# Firmware

This section will cover installing and updating RotaryCell firmware as part of a new build.

For the current source and binaries, see the repository's `firmware/current` and `firmware/prebuilt` directories. Detailed build-from-source instructions remain in `FIRMWARE_BUILDING.md` at the repository root.
