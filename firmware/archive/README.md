# Firmware archive

These ZIP files preserve prior development checkpoints from v0.1 through v0.10.3. They are retained for comparison and recovery, not as supported releases.

The earlier stable source is in `../current/ESP-RotaryCell_v0.10.4`, with its
source ZIP and OTA application binary in `../prebuilt`. The illustrated PCB
guide uses `../../development/firmware/ESP-RotaryCell_v0.11.1-dev`.

Some early version numbers have more than one branch because the experiments had different behavior. Their descriptive filenames have been preserved.
