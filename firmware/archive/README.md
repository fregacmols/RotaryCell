# Firmware archive

These files preserve prior development checkpoints from v0.1 through v0.10.4.
They are retained for comparison and recovery, not as the firmware used by the
current illustrated build.

The earlier stable v0.10.4 source is in `ESP-RotaryCell_v0.10.4`, with its
source ZIP and OTA application binary in `../prebuilt`. The illustrated PCB
guide uses `../current/ESP-RotaryCell_v0.11.1-dev`.

Some early version numbers have more than one branch because the experiments had different behavior. Their descriptive filenames have been preserved.
