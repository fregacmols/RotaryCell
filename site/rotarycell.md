# RotaryCell

RotaryCell is a personal engineering project that gives a Western Electric/AT&T Model 500 rotary telephone a self-contained cellular connection while retaining its rotary dial, handset, and mechanical bell.

The current prototype can place and receive calls and includes period-inspired dial, reorder, and receiver-off-hook tones. Development is ongoing; this is not yet a product, kit, or public release.

The working repository is maintained privately on GitHub for backup and remote access. Technical files and build instructions will be published here if the project reaches a suitable release stage.
